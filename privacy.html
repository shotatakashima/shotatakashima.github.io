Privacy Policy

Wine Mail Intake · effective 2026-10-31 · Home

Who uses this app

Wine Mail Intake is a personal tool used only by its owner, with the owner's own Google account. It has no other users and is not offered to the public.

Google data accessed

  • Gmail, read-only (https://www.googleapis.com/auth/gmail.readonly).
  • Only messages matching a search for order, shipping and delivery notifications from a fixed list of wine retailers and shipping services are read.
  • The app never sends, deletes, modifies, labels or marks messages as read.

How the data is used

The app runs on the owner's own computer (self-hosted n8n, bound to that computer only). A message's subject and text are processed in memory only to extract wine purchase and shipping information, and are then discarded. Message subjects, message text, attachments, names, addresses and payment details are not stored, and run logs are not saved.

What is stored, and where

On the owner's computer only:

  • Message metadata: Gmail message and thread IDs, message date, sender domain, a hash of the content, and the classification result.
  • Extracted purchase and shipping details: retailer, order and tracking numbers, wine name, vintage, number of bottles, price, dates and status.
  • The Google sign-in token, encrypted by n8n with a key kept in the macOS Keychain.

Local backups of the same data are kept on the same computer (the most recent ten).

Sharing

  • For each new purchase or shipment, a proposal with the wine name, vintage, number of bottles, date, domestic or overseas delivery, price and retailer is posted to the owner's own private GitHub repository (GitHub, Inc.), so that the owner can approve or reject it. Order numbers, tracking numbers, message content and personal information are not included.
  • Only proposals the owner approves are written to the owner's personal notes (stored in the owner's iCloud Drive).
  • When maintaining or troubleshooting the app, the owner may use an AI assistant. In that case only the minimum information needed for the task may be shared with it; sign-in credentials and complete message content are not shared.
  • Apart from the above, Google user data is not sold, not used for advertising, not shared with anyone else, and not used by the app to develop, improve or train AI or machine-learning models.

Limited Use

Wine Mail Intake's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data is kept on the owner's computer until the owner deletes it. Access can be revoked at any time in the Google Account permissions page; the app then can no longer read Gmail.

Changes and contact

Changes to this policy are published on this page with a new effective date. Contact: the owner via GitHub (github.com/shotatakashima).
